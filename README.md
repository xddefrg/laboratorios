# Laboratorio 1 — Introducción a Python

Este laboratorio presenta los fundamentos del lenguaje Python: variables, tipos de datos, entrada y salida, operadores, conversiones y cálculos básicos.

## Ejercicios básicos

| Archivo | Descripción y función |
|---|---|
| `hola_python.py` | Imprime el primer mensaje en pantalla y confirma la ejecución de Python. |
| `presentacion.py` | Presenta datos personales o académicos utilizando `print()`. |
| `saludos.py` | Practica la impresión de mensajes simples. |
| `datos_basicos.py` | Declara variables básicas y muestra su contenido. |
| `datos_usuario.py` | Solicita información al usuario con `input()` y la muestra. |
| `perfil_aprendiz.py` | Construye un perfil a partir de datos almacenados en variables. |
| `tipo_entrada.py` | Ejemplifica cómo se reciben los datos escritos por el usuario. |
| `Ejercicio.py` | Contiene un ejercicio inicial de práctica con variables o salida. |
| `Programa_incompleto.py` | Presenta una estructura incompleta que debe completarse o depurarse. |
| `errores.py` | Muestra errores comunes de sintaxis, texto sin comillas y nombres incorrectos. |
| `error_variable.py` | Demuestra el error provocado al usar o escribir mal el nombre de una variable. |

## Variables y tipos de datos

| Archivo | Descripción y función |
|---|---|
| `inventario.py` | Declara datos de un producto y muestra sus valores. |
| `reto_producto.py` | Define una ficha de producto con código, nombre, categoría, precio, cantidad e impuesto. |
| `EjercicioCosecha.py` | Utiliza variables para representar datos relacionados con una cosecha. |
| `EjercicioTimote.py` | Practica el manejo de variables con un caso contextual diferente. |

## Operadores y cálculos

| Archivo | Descripción y función |
|---|---|
| `operadores.py` | Ejemplifica operadores aritméticos y operaciones básicas. |
| `calculo.py` | Realiza un cálculo sencillo con variables numéricas. |
| `calculo_promedio.py` | Suma o procesa notas para calcular un promedio. |
| `calculo_compra.py` | Calcula subtotal, descuento y total de una compra a partir del precio y la cantidad. |
| `calculo_salario.py` | Calcula una información salarial usando datos numéricos y operaciones. |
| `cotizador_compra.py` | Calcula el valor de una compra y presenta sus resultados. |
| `factura_simple.py` | Organiza datos y totales para representar una factura sencilla. |
| `suma_interactiva.py` | Solicita dos números y muestra su suma. |
| `salario_interactivo.py` | Solicita datos salariales al usuario y realiza el cálculo correspondiente. |

## Conversiones y entradas

| Archivo | Descripción y función |
|---|---|
| `conversor_temperatura.py` | Convierte una temperatura entre las escalas configuradas en el ejercicio. |
| `conversion_unidades.py` | Convierte valores de una unidad a otra. |
| `conversion de tiempo.py` | Convierte una medida de tiempo mediante operaciones aritméticas. |

## Ejecución

Ejecute cualquier ejercicio desde la carpeta `laboratorio 1`:

```bash
cd "laboratorio 1"
python nombre_del_archivo.py
```

Por ejemplo:

```bash
python reto_producto.py
python calculo_compra.py
python suma_interactiva.py
```

## Conceptos trabajados

- Variables y asignación de valores.
- Tipos de datos numéricos, texto y booleanos.
- Entrada de datos con `input()`.
- Conversión de texto a números con `int()` y `float()`.
- Operadores aritméticos y expresiones.
- Impresión con `print()` y cadenas formateadas.
- Cálculo de totales, descuentos y promedios.
- Identificación y corrección de errores básicos.
