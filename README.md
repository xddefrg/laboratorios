# LAB-07 Classroom-hub
Esta es una version temprana de classroom-hub esta version solo incuye:

Páginas principales: inicio, información y recursos.

Modelo Resource: representa los recursos con nombre, descripción, enlace y tipo.

Migraciones: crean y actualizan la estructura de la base de datos.

Vistas y rutas: controlan qué contenido se muestra al usuario.

Plantillas HTML: muestran la interfaz común y las páginas del sitio.

Administración Django: permite gestionar los recursos desde el panel administrativo.
